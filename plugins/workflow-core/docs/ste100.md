# Writing rules: ASD-STE100 (STE-lite)

These rules apply when `writing.style` is `ste100`. They are a short form of ASD-STE100 Simplified
Technical English. The full standard has a controlled dictionary. This file does not include it.

`node "<wc>" prose <file>` checks the rules that a script can check. Rules marked "(checked)" are in
the script. Use your judgment for the other rules.

## Words

- Use one word for one meaning. Use the same word for the same thing in all of the text.
- Use short, common words. Use `use`, not `utilize`. Use `start`, not `commence`. (checked)
- Use a verb for an action. Write "check the file", not "do a check of the file".
- Use technical names (file names, commands, functions) exactly as they are. Put them in `code`.
- Do not use slang, idioms or jokes.

## Sentences

- Write one instruction in one sentence.
- An instruction has 20 words or fewer. A description has 25 words or fewer. (checked)
- Write instructions in the imperative: "Run the tests."
- Use the active voice. Say who or what does the action: "The tester runs the checks", not
  `The checks are run`. (checked)
- Use the present tense for descriptions.
- Put a condition first: "If the check fails, stop."
- Do not leave out "the", "a" or "that" to make a sentence shorter.

## Paragraphs and lists

- A paragraph has one topic and six sentences or fewer. (checked)
- Use a numbered list for steps in sequence. Use a bulleted list for items without a sequence.
- Give a warning or a caution before the step that it is about.

## What the script does not check

The script does not check the dictionary, the meaning of words, one instruction per sentence,
tense or the order of conditions. It skips code, tables, headings and frontmatter. To skip a block
that must stay as it is (for example, an exact output format), put `<!-- prose-ignore -->` on the
line before it.
